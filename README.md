# sap-gui-async
SAP GUI 800 - C# Desktop App

This tool uses the SAP RFC SDK (SapFunctionsOCX).

This should not be used without a SAP license agreement.

The tool logs into SAP and uses the Remote Function BAPIs to transmit data to and from SAP.

current functionality is to download data from tables and manipulate to provide immediate data to users without having to know the ins and outs of SAP.

Stage 1 - In progess
SAP costing data

Stage 2 - Not started
Sales order creation and status

Stage 3 - Not started
MM and WM transactions for users
